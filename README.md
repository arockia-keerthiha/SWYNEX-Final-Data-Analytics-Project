# SWYNEX Final Data Analytics Project

## Project Title
Cafe Sales Data Analytics — Final Case Study

## 1. Problem Statement
The purpose of this project is to analyze café sales data, identify data quality issues, understand sales performance, and discover useful business insights.

## 2. Dataset Information
- Dataset: Cafe Sales Dataset
- Total Records: 10,000 transactions
- Total Columns: 8
- Key columns: Transaction ID, Item, Quantity, Price Per Unit, Total Spent, Payment Method, Location, Transaction Date.

## 3. Tools Used
- Microsoft Excel
- Power BI
- GitHub

## 4. Data Cleaning
- Checked missing values and inconsistent entries.
- Identified ERROR and UNKNOWN values.
- Replaced problematic entries with UNKNOWN where appropriate.
- Prepared the dataset for further analysis.

## 5. Exploratory Data Analysis
Analyzed transaction counts, recorded sales amounts, quantities sold, product performance, payment methods, and transaction locations.

## 6. Dashboard
An interactive dashboard was developed using Power BI to present key performance indicators, charts, and filters.

## 7. Key Business Insights
- Salad had the highest recorded sales amount among the listed products in the initial analysis.
- Juice had the highest recorded quantity sold among the listed products.
- Digital Wallet was the most frequent named payment method.
- Takeaway had slightly more recorded transactions than In-store.
- Unknown and problematic records highlight the importance of data quality checks.

## 8. Conclusion
This project helped me gain practical experience in data cleaning, exploratory data analysis, visualization, and communicating business insights.
